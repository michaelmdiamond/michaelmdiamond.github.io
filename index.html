About

Product-minded software operator working across AI tooling, consumer workflows, and practical internet businesses.

My best work starts when the problem is still fuzzy: the user workflow is unclear, the product shape is up for debate, and the fastest path forward is a concrete artifact people can react to. I care about prototypes that teach, systems that stay understandable, and software that survives contact with real users.
